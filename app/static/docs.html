Product

Terminal workflow

  • Enter one ticker, a comma list, or a public TradingView watchlist URL.
  • Pick a mode (Auction, Ridge, Compass, Cockpit, Brief, Alerts, …) and run.
  • Export JSON from the result panel, or sign in to save research to the Library.
  • Alert Monitor can save daily rules and test webhook delivery when Supabase is configured.
HTTP API

API reference

Base URL is this host. Local default: http://127.0.0.1:5050. JSON bodies use Content-Type: application/json. Errors look like { "error": "…" }.

Full markdown copy: /docs/api.md · GitHub source: docs/api.md

Ticker selection

Charts, analysis, cockpit, alerts, and torque scan accept one of ticker, tickers, or watchlist_url. Optional max_results defaults to 10 (cap 50).

Health & config GET /api/health, /api/config Charts POST /api/charts/<type> Analysis GET/POST /api/analysis Watchlists resolve, cockpit, alerts Scheduler Bearer ALERT_SCHEDULER_TOKEN Tools fax, vision, torque, pixel…
HTTP API

Health & config

GET /api/health

curl -s http://127.0.0.1:5050/api/health
{ "ok": true, "service": "underlying-analyzer-reboot" }

GET /api/config

Public Supabase client values only. Never returns service-role secrets.

curl -s http://127.0.0.1:5050/api/config

GET /api/providers

curl -s http://127.0.0.1:5050/api/providers
HTTP API

Charts

POST /api/charts/<chart_type>

Type Purpose Extra fields
auction Auction levels period (default 1y)
performance Monthly seasonality month (1–12)
regression Regression channel period, start_date, end_date
ridge-growth Ridge strategy pack ticker / watchlist
flow-compass Flow indicator period
torque Torque chart period (default 2y)
portfolio Multi-ticker portfolio investment_per_stock, dates
volatility Vol compare ticker / watchlist 
curl -s -X POST http://127.0.0.1:5050/api/charts/auction \
  -H 'Content-Type: application/json' \
  -d '{"ticker":"AAPL","period":"1y"}'
HTTP API

Analysis

GET /api/analysis/<ticker>

curl -s http://127.0.0.1:5050/api/analysis/AAPL

POST /api/analysis

curl -s -X POST http://127.0.0.1:5050/api/analysis \
  -H 'Content-Type: application/json' \
  -d '{"tickers":["AAPL","MSFT"],"max_results":10}'

Requires ANTHROPIC_API_KEY for generated brief text.

HTTP API

Watchlists

POST /api/watchlists/resolve

curl -s -X POST http://127.0.0.1:5050/api/watchlists/resolve \
  -H 'Content-Type: application/json' \
  -d '{"watchlist_url":"https://www.tradingview.com/watchlists/334089913/","max_results":10}'

POST /api/watchlists/cockpit

curl -s -X POST http://127.0.0.1:5050/api/watchlists/cockpit \
  -H 'Content-Type: application/json' \
  -d '{"tickers":["AAPL","MSFT"],"max_results":10}'

POST /api/watchlists/alerts

curl -s -X POST http://127.0.0.1:5050/api/watchlists/alerts \
  -H 'Content-Type: application/json' \
  -d '{"tickers":["AAPL","MSFT"],"max_alerts":5}'
HTTP API

Alerts scheduler

GET /api/alerts/scheduler/status

curl -s http://127.0.0.1:5050/api/alerts/scheduler/status

POST /api/alerts/scheduled/run

Requires Authorization: Bearer <ALERT_SCHEDULER_TOKEN>.

curl -s -X POST http://127.0.0.1:5050/api/alerts/scheduled/run \
  -H "Authorization: Bearer $ALERT_SCHEDULER_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{}'

POST /api/alerts/webhook/test

Requires a Supabase user access token and rule_id.
